# LEAF · Site em HTML e CSS

Site de três páginas feito só com HTML e CSS, **baseado no meu projeto de pesquisa LEAF** (Low-Cost Ecological AgroCare Framework), que estuda agricultura de precisão acessível e sustentável com visão computacional, ESP32 e proteção ecológica de culturas.

Projeto original: https://github.com/henriquebrtocosta/leaf-cmjf

## Páginas

- `index.html`: apresentação do tema.
- `about.html`: objetivos, funcionamento e pesquisa do projeto.
- `contact.html`: formulário de contato demonstrativo.
- `style.css`: estilos compartilhados.
- `images/`: ilustrações usadas no site.

## Sobre o formulário

É só uma demonstração: usa GET para a própria página, não salva nem envia mensagens. Use dados fictícios, porque os valores aparecem no endereço do navegador.
